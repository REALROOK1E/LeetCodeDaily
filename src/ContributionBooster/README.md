# Contribution Booster

这个文件夹用于增加 GitHub 贡献热点图的提交次数。

## 文件说明
- `DailyCommit.java` - 每日提交生成器
- `RandomCode.java` - 随机代码生成器
- `CommitHelper.java` - 提交辅助工具

## 使用方法
1. 每天运行一次 `DailyCommit.java`
2. 使用 `RandomCode.java` 生成随机代码
3. 用 `CommitHelper.java` 批量提交

## 注意事项
- 这只是为了增加贡献次数
- 实际开发中请保持代码质量
